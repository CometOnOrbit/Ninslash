# 动作精修 V2

使用已有的 Sunburst 贴图，重做骨架分层和全部九组动作。此次没有调用图像生成接口，也没有改变游戏内 AI 或伤害代码。

- [精修版预览](preview-motion-v2.html)，支持初版对照、慢放、拖动时间轴、骨骼挂点显示、关闭特效和录制当前动作。
- 预览内的“初版对照”使用 `source/reference-rig.json` 中固定保存的参考动作。
- `source/` 保存重建所需的原始骨架、贴图和时间参数。
- 原生资源：`data/anim/foundry_warden/warden-motion-v2.{json,atlas,png}`。
- `warden-motion-v2.combat.json` 是配套动作时间标记和挂点说明，不是引擎自动执行的 AI 配置。

## 这次的动作变化

**承重结构。** 底盘与上身分别驱动。四足按世界坐标约束支撑点，行走时采用对角承重和摆动足弧线；离地之前先绕脚尖滚动，落足后才压下身体。根据实际鞋底贴图修正接触高度，避免脚底悬空。

**关节传力。** 液压钳按肩、肘、腕、钳指的顺序发力，接触时保持短暂姿势；护板和炮管随后回弹。液压套筒和滑杆从实际两个挂点求方向和伸缩，避免摆臂时断开。

**攻击节奏。** 使用缓入、加速释放、过冲和阻尼回弹构建曲线，再烘焙成普通关键帧。重踏包含压低重心、弹道式起跳、收腿、落地压缩、上身二次压缩与收束。蓄力时的钳尖穿地也已通过调节肘腕姿势修正。

**部件独立运动。** 左右炮交替开火，后坐先发生在炮管，再传给炮架和躯干。胸甲先卸压，再左右错峰解锁；炉芯和传感器发光部分独立于外壳，死亡时保留实体金属环。

**体积和层次。** 后排腿使用较暗的同源纹理，前后脚有独立脚尖。接地阴影随离地高度变化，重踏和炮击使用实际挂点生成冲击、火花与烟气。

## 资源与验证

共 54 根骨骼、49 个插槽、26 个纹理区域。原贴图的主体保持不变；额外区域来自原贴图的脚掌、眼睛、核心分层及后排腿阴影处理。素材来源仍见 [ATTRIBUTION.md](ATTRIBUTION.md)。

制作曲线以 60 Hz 烘焙，再进行受误差限制的关键帧精简，当前共 10,045 个导出关键帧。原生资产只使用引擎已支持的 region 附件、骨骼旋转、位移和缩放，不要求新增运行时 IK 或网格形变支持。

`verify_motion.py` 独立读取导出的 JSON 和 PNG，每个动作采样 121 个姿势，检查关键帧时间、旋转跨度、支撑点误差、循环接缝及可见轮廓。当前导出支撑点最大高度误差约 **0.234 个设计坐标单位**，待机和行走的循环首尾矩阵一致；所有姿势均处于预览边界内。像素边缘的地面容差为 0.85 个单位，实际最低轮廓点为 −0.291。详细结果见 `motion-validation.json`。

项目真实的 `CSpineReader::Load`／`LoadAtlas` 已成功解析新资源，并检查父子引用、纹理路径和插槽映射。这些验证针对资产及预览，**不等于已经在游戏对局中完成测试**。

## 原生动作与预览表现的边界

骨架分层、脚部约束结果、脚尖滚动、液压杆、惯性跟随、接触持姿与核心分层均包含在导出的 JSON／PNG 中。

动作切换的 180 毫秒混合、火花烟气、镜头反馈、接地阴影、发光晕及行走背景滚动由预览实现。它们的时间标记和挂点已写入配套说明；接入游戏时需绑定到 Ninslash 的客户端效果与状态机。关闭预览“打击与散热特效”即可单独评估骨骼运动。

保持原生读取器的时间限制：其动画求值使用 `fmod`；单次动作需要由调用者在结束时钳制到 `duration - epsilon`。行走根骨不移动实体，应由服务器速度驱动位置、由移动速度调整步频。

## 重建

```powershell
python design/foundry-warden/polish_animation.py
python design/foundry-warden/verify_motion.py
cmake --build build --config Release --target ninslash_test_foundry_warden
ctest --test-dir build -C Release -R foundry_warden_assets --output-on-failure
```

Python 命令需要 Pillow（版本固定于 `requirements.txt`）。原生验证目标需要启用 `NINSLASH_BUILD_TESTS`；其源文件为 `validate_native.cpp`。重建会从固定的制作输入生成 V2 资源和当前预览。配置步骤见 [README.md](README.md)。
